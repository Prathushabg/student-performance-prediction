# 🎓 EduPredict AI

An AI-powered Student Performance Prediction System built using Machine Learning and Streamlit.

## Features

- 🔐 Login System
- 🤖 Student Performance Prediction
- 📊 Interactive Dashboard
- 📜 Prediction History
- 💾 SQLite Database
- 📈 Data Visualization

## Technologies

- Python
- Streamlit
- Scikit-Learn
- Pandas
- Plotly
- SQLite
- Joblib
